# repository-walmart-analysist

# Анализ продаж Walmart

Анализ данных о недельных продажах 45 магазинов Walmart (2010–2012) с использованием Python (pandas, matplotlib) и SQL.

## Что сделано
- Загрузка и проверка данных (6 435 записей, пропусков нет)
- SQL-запросы: сравнение продаж в праздничные и обычные недели, топ-20 магазинов по выручке, динамика продаж по месяцам
- Визуализация ключевых метрик

## Основные выводы
- В праздничные недели средняя выручка выше на ~7.8% (1 122 888 против 1 041 256)
- Лидер по общей выручке — магазин №20 (~301 млн), за ним №4 и №14
- Продажи демонстрируют чёткую сезонность: резкий пик в декабре (предновогодний период) и спад в январе

## Стек
Python (pandas, matplotlib), SQL (SQLite)
